This skill repackages Magic UI's "Icon Cloud" (https://magicui.design) idea
(a rotating 3D sphere of icon tiles). The implementation here is an
independent, dependency-free rewrite (DOM + CSS transforms + requestAnimationFrame,
plain CSS instead of Tailwind, black-gray defaults, drag-to-spin with inertia,
`prefers-reduced-motion` support). The upstream MIT notice above is retained as
required. Brand logos used in the demo come from Simple Icons (CC0-1.0).
